# Security policy

## Supported version

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or send a private message to the repository owner. Do not disclose vulnerabilities, credentials, personal information, or exploit details in a public issue.

Include:

- A clear description of the issue
- Reproduction steps
- Expected security impact
- A suggested fix, if available

Please allow reasonable time for investigation and remediation before public disclosure.
