# Идеи

Сюда записываем всё, что, возможно, захочется сделать в проекте. Это не планы, не обязательства и не утверждённые требования. Порядок записей ничего не означает.

Когда решаем заняться идеей, для неё создаётся отдельная спецификация в `docs/features/`, а запись отсюда удаляется. Ненужные идеи тоже можно просто удалять — история останется в Git.

## Список

- Обновить и расширить фотогалерею новыми работами.
- Сделать бэк-офис для управления текстами и фотографиями без изменения кода.
- Добавить линтинг и небольшие автоматические тесты.
